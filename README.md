# الفرات الحلو لتحلية المياه — نسخة PHP/MySQL (Hostinger)

موقع + لوحة تحكم شغّلان على أي استضافة PHP عادية. نفس الموقع تمامًا الذي كان يعمل على Node،
لكن الخادم الآن PHP خالص مع قاعدة بيانات MySQL — لا Node ولا npm ولا PM2 على سيرفركم.

---

## لصاحب المحل (عبدالرحمن المنقاش) — 4 خطوات فقط

1. **ارفع الملفات**: افتح «مدير الملفات» في لوحة Hostinger → مجلد `public_html` → ارفع كل
   محتويات مجلد `public_html` من هذا الملف المضغوط إلى داخله (اسحب مجلد `assets` ومجلد `app`
   ومجلد `data` والملفات `index.php` و `.htaccess` و `install.php`).
2. **أنشئ قاعدة بيانات**: لوحة Hostinger ← «قواعد البيانات MySQL» ← أضف قاعدة جديدة
   (اسم قاعدة/مستخدم/كلمة سر — احتفظ بها). ثم اكتب هذا الرابط في المتصفح:
   `https://دومينك.com/install.php` — الصق البيانات الأربعة واضغط الزر.
   الموقع سينتقل تلقائيًا لقاعدة البيانات وينسخ إليها كل منتجاتك وصورعملاءك الحاليين.
   **بعد نجاح التثبيت احذف ملف `install.php` من السيرفر** (يكتبها لك الموقع في آخر الشاشة).
3. **افتح موقعك**: `https://دومينك.com` — لوحة التحكم: `https://دومينك.com/admin`
   برمز الدخول الحالي. **غيّر الرمز فورًا من تبويب «الأمان»** داخل اللوحة.
4. **شهادة HTTPS**: من لوحة Hostinger ← «SSL» ← فعّل الشهادة المجانية.

> بياناتك (منتجات، صور، عملاء) محفوظة كلها على سيرفرك وحدك في قاعدة MySQL الخاصة بك،
> مع نسخة احتياطية تلقائية في مجلد `data/backups` (آخر 7 لقطات يومية، لا تغادر السيرفر).
> كل شيء يعمل أيضًا بدون قاعدة بيانات (ملفات JSON) لو أردت — التحويل تلقائي.

## للمنفذ التقني

- **المتطلبات**: PHP 8.1+ مع إضافات `gd` و `mysqli` و `exif` (كلها مفعّلة في Hostinger افتراضيًا).
- **البنية**: `index.php` موجّه وحيد (Front Controller) — كل المسارات تمر به عبر `.htaccess`.
  مجلد `app/` فيه الطبقات: `render.php` (العرض)، `store.php` (MySQL kv + تراجع JSON)،
  `auth.php` (اللوحة)، `upload.php` (ضغط الصور عبر GD)، `art.php` (رسوم المنتجات)،
  `export.php` (النسخة المستقلة)، `qr.php` + `qrlib/` (بطاقات QR).
  مجلد `data/` ممنوع من الوصول المباشر (`.htaccess`) ويحتوي: `data.json`، `customers.json`،
  `admin-auth.json`، `stats.json`، `backups/`، و`db-config.json` (يُنشأ عند التثبيت).
- **قاعدة البيانات**: جدول واحد `kv(name, doc, updated_at)` بترميز utf8mb4.
  المستندان: `data` و `customers`. إن حُذفت القاعدة أو تعطلت، الموقع ينتقل تلقائيًا لملفات JSON
  فلا يقع أبدًا. لنقل بيانات من وضع لآخر شغّل `install.php` من مجلد الموقع:
  `php install.php --host=localhost --user=U --pass=P --db=DB`
- **النسخ الاحتياطي**: لقطة تلقائية عند كل حفظ + زِر «تنزيل نسخة احتياطية» في اللوحة.
  اختياري لقطة يومية بمهمة Cron في Hostinger: `php {path}/snapshot-cron.php` الساعة 3 فجرًا.
- **لوحة HSTS/الأمان**: الرؤوس مضمنة في الكود؛ فعّل «حماية Hotlink» و SSL forcé إن أحببت.
- **سلة المشتريات والدفع**: السللة والطلب عبر واتساب تعملان كما هما؛ بوابة الدفع الحقيقي ما زالت مؤجلة بطلب المالك.

## ما تغيّر عن نسخة Node

- الخادم Node/Express استُبدل بـ PHP كامل — **الواجهة (HTML/CSS/JS) نفسها بالحرف**،
  وكل مسارات API ونسخ البيانات والرموز ولقطات النسخ تعمل بنفس العقود بالضبط.
- لوحة التحكم، السلة، واتساب، الخريطة، بطاقات QR، «نسخة مستقلة» للتصدير — كلها كما هي.
- تحسين الصور وقت الرفع يستخدم مكتبة GD بدل sharp: الناتج صورة مربعة خلفية مطبعية مموّهة
  ≤1400px مضغوطة، تمامًا كسلوك النسخة السابقة.
- الإصلاح الوحيد السلوكي: زر «تصدير نسخة مستقلة» كان يرجع خطأ في النسخة الأخيرة من Node؛ صار يعمل.


## (اختياري) التحديث التلقائي عبر GitHub — مثل نظام النشر السابق
جهّزنا نظامًا يعيد نفس راحة Render: المصمم يدفع تحديثًا على مستودع GitHub (furat-push)، والموقع على Hostinger
يسحبه تلقائيًا كل 10 دقائق — **الكود فقط، وبيانات المحل ما تُلمس أبدًا** (مستودع التحديث لا يحتوي
بيانات منتجات حية ولا عملاء ولا إعدادات قاعدة ولا مفاتيح — يراجعها المالك بنفسه إن شاء).

الخطوات للفني (مرة واحدة):
1. تأكد أن التركيب تم كما فوق (ZIP + install.php حُذف + اللوحة شغالة).
2. من SSH بلوحة Hostinger: عيّن رابط المستودع وشغّل السكربت مرة يدويًا:
   `export FURAT_REPO_URL="رابط_المستودع" && bash <(curl -s https://raw.githubusercontent.com/FerasFuad34/furat-push/main/deploy/furat-deploy.sh)` — أو انسخ مجلد `deploy/` من المستودع لـ `~/furat-src/deploy/` وشغّله.
3. مهمة CRON باللوحة كل 10 دقائق:
   `*/10 * * * *` → `FURAT_REPO_URL="https://github.com/FerasFuad34/furat-push.git" bash $HOME/furat-src/deploy/furat-deploy.sh >> $HOME/furat-deploy.log 2>&1`
4. انتهى — كل `git push` من المطور يظهر بموقعكم خلال 10 دقائق، ولو كان التثبيت مكتملًا يحذف السكربت install.php تلقائيًا بعد كل مزامنة فلا يعود يظهر.

تفاصيل الضمانات والحارس المزدوج في `README-DEPLOY.md` داخل المستودع.
